# 草坪接力：植物大战僵尸终端对战

本模式使用现有Go规则引擎、Bubble Tea终端、WebSocket房间与服务端100ms时钟。双人各自防守一块5×9草坪，游戏页面始终只显示一块草坪，Tab或V切换查看对方实时草坪。查看对方时只读，不暂停自己的战斗。

## 本次已确认范围

- 双人房间、实时种植/战斗、人机练习、共享聊天与在线玩家、排行榜和战绩、F2续局、Del离桌机器人接管。
- 任意方式击败的僵尸（弹丸、爆炸、吞噬、地雷、窝瓜），结算后恢复完整生命及护甲，出现在对方同一行最右侧。
- 保留种类，每次死亡都再次转移；清除减速，重置攻击、召唤、撑杆和报纸狂暴状态。护甲被打碎不改变永久种类。
- 舞王召唤的伴舞也参与转移。转移不会在同一时钟周期再次被对方攻击，避免跨草坪递归爆炸和遍历顺序偏差。
- 没有小推车；僵尸越过草坪左边界到达脑子即失败。同周期双方失守判平。
- 十种植物：向日葵、豌豆射手、坚果、樱桃炸弹、寒冰射手、火爆辣椒、双发射手、大嘴花、土豆雷、窝瓜。
- 九种僵尸：普通、路障、铁桶、舞王、伴舞、撑杆、报纸、橄榄球、铁栅门。
- 自行设计的彩色字符造型、冷却/阳光/威胁提示、弹丸、命中与爆炸效果，暂时沿用酒馆背景曲及现有合成短音效。

## 操作

| 按键 | 作用 |
| --- | --- |
| 大厅G | 进入本模式，2真人房间 / 4人机练习 |
| Tab / V | 自己与对方草坪切换，任意时刻可看 |
| 方向键 / WASD | 移动格子光标，边缘循环 |
| 1–9 / 0 | 选择第1–10张植物卡 |
| 鼠标左键点击植物卡 | 选中植物并退出铲子状态，再点击自己的草坪种植；冷却/阳光不足有提示 |
| Enter / 空格 | 种植，铲子状态则移除植物 |
| 鼠标左键点击格子 | 使用当前植物卡或铲子 |
| X / Esc | 切换铲子 / 返回种植 |
| /、F3、F4、F6–F8 | 沿用聊天、中文短语、在线玩家和消息范围 |
| F1 / M | 规则 / 音乐开关 |
| F2 / Del | 结束后续局 / 离桌回到本模式大厅 |

## 初版节奏与边界

开局3秒倒计时，初始150阳光，每5秒自动获得25阳光。向日葵每10秒产25；种植有费用及独立卡片冷却，铲除不退款。所有操作由服务端检查，不允许在对方草坪种植。

正式开始15秒后首波；双方新波的种类和行相同，之后新波间隔由约16秒缩短，最低3秒；移动速度每两分钟提高10%，最高两倍。难度按照模拟时间，服务端停顿不无限补帧；初版数值为本模式参数，不宣称原版一比一。

护甲优先承担弹丸伤害，溢出伤害进入本体。铁栅门护甲未破时抵挡寒冰减速；报纸护甲破损后加快移动。撑杆只跳一次，舞王只召唤一次，但转移后恢复原始行为。爆炸、吞噬和压毁忽略护甲。

全场最多120个僵尸，达到容量时暂停新波和新增伴舞；死亡转移不会减少总数，不会因对方拥挤丢弃敌人。每草坪弹丸最多256，短效果最多32。机器人只读取自己的公开草坪，种植沿用真人费用和冷却检查。

至少40列×21行的游戏可用区域；植物卡自动分成2–4行，十种植物均可见并可点击。卡片使用固定点击区域，费用与冷却变化不会改变位置；草坪位置按卡片行数同步计算。窗口较小时降低草坪每格高度。字体决定字符效果，聚集敌人显示Zx数量，底部提示最靠近脑子的敌人所在行。聊天、规则弹窗及查看对方不暂停对局。

## 参考来源和代码边界

阅读[soizo/npvz](https://github.com/soizo/npvz)的植物、僵尸、弹丸与绘制公开实现，参考其行为分工、护甲溢出、报纸加速、撑杆与卡片冷却等细节。该项目为C/ncurses、Apache-2.0；本模式新增Go实现和字符造型，没有导入其源文件、Emoji绘制、ASCII素材、二进制或音频。复活接力、同步结算、房间联网与上述平衡参数是本项目设计。
