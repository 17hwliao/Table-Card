# 终端全部操作：无需中文输入

界面、规则和剧情保留中文。必须填写的地址、房间号、昵称、游戏选择、物品和剧情动作均可使用ASCII字母/数字；中文别名作为兼容入口保留。聊天可用英文或编号中文短语，无须输入法。

## 通用入口

| 场景 | 所有选项与操作 |
| --- | --- |
| 启动器 | 客户端数量1–16；房主地址如`192.168.1.20:1781`；昵称如`Alice`、`Player1`、`123`；玩家包昵称直接回车默认Player1 |
| 游戏选择 | 1斗地主、2骗子酒馆、3川麻、4象棋、5国际象棋、6五子棋、7围棋、8UNO、9俄罗斯方块、0贪吃蛇、P宝可梦；Enter进入；↑↓选择；E编辑昵称；M声音；F5重新连接；Q退出 |
| 网络模式菜单 | 1快速匹配、2真人房间、3输入六位房间号、4人机练习、5排行榜、6战绩、7规则、8返回；←→调整人数；O房规（川麻/UNO）；E昵称；Esc返回 |
| 正在创建/加入/匹配 | Esc或Del取消；清理临时座位后可重试。HTTP请求与WebSocket握手共用15秒总期限，单次网络请求最多8秒；清理退出另有短暂等待 |
| 等待房间 | R准备或取消、S开始、/英文聊天、F3编号短语、Esc退出房间 |
| 多人对局 | Del离桌、F1规则、F2结束后再开、M声音、/英文聊天、F3编号短语 |
| 自由聊天 | Enter发送，Esc返回游戏；输入期间字母不会触发出牌或音乐快捷键 |
| F3短语 | 1准备好了、2等我一下、3轮到你了、4好牌、5这局很精彩、6再来一局、7谢谢、8我先离开啦、9祝你好运；数字直接发送；Esc/F3取消 |
| 规则/战绩长页 | ↑↓或PgUp/PgDn滚动，Esc/Enter关闭；文字按终端宽度换行 |
| 房规页 | ↑↓选择项目，←→/Enter/Space轮换值，Esc返回；创建后房规固定 |
| 客户端退出 | Ctrl+C；宝可梦会先存档；多人进行中的座位交给机器人 |

## 十一种游戏

| 模式 | 游戏操作 |
| --- | --- |
| 斗地主 | 叫分1/2/3，P不叫/过牌；←→或H/L移动，Home/End跳到两端，Space选择/取消，1–9快选，Enter出牌，Esc清空 |
| 骗子酒馆 | 1–9选择/取消手牌，Enter盖牌，C质疑，Esc清空；公示及枪决期间等待提示 |
| 川麻 | 换三张：←→或H/L移动，Space或1–9/0选牌，Enter提交同花色三张；定缺1万/2筒/3条；D摸牌，←→或H/L及1–9/0选牌，Enter出牌；Z胡，P碰，G明杠/补杠，B暗杠，N/Space过；结算Enter下一局 |
| 中国象棋 | 鼠标点己方棋子，再点目标；也可方向键/WASD/HJKL移动光标，Enter选子/落子；Esc取消选子 |
| 国际象棋 | 同象棋；兵升变预选Q后/R车/B象/N马，再完成走子；默认升后 |
| 五子棋 | 鼠标落子；方向键/WASD/HJKL移动光标、Enter落子 |
| 围棋 | 鼠标或光标+Enter落子，P停一手；连续两次停一手结算 |
| UNO | ←→或数字选牌，Enter出牌；R/Y/B/G选红黄蓝绿，U标记本次喊UNO，C抓漏喊，D摸牌/接受罚牌，K保留摸到的牌结束回合，X挑战+4，T或[ ]选择7换手对象，V切换双牌同出（须房规开启），Esc取消 |
| 俄罗斯方块 | ←→或A/D平移，↑/W顺时针旋转，↓/Z逆时针，S加速下落，Space落底；服务器持续推进，与聊天、规则页并行 |
| 贪吃蛇 | 方向键/WASD，Enter/Space开始，P/Space暂停或继续，Esc暂停，F2/R重开，Del/Q返回；输入转向有缓冲和反向过滤 |
| 宝可梦 | 本页数字+Enter；M地图/C中心/W世界/H指南/P队伍/B背包/Q支线/V对手也需Enter；[ ]/←→翻页，0/Esc上层，↑↓阅读说明，PgUp/PgDn历史，F5/Ctrl+S存档，F9声音，Del保存返回 |

川麻数字0选择第十张；第十一张以后用←→或H/L移动选择。UNO和斗地主手牌较多时也用光标访问后面的牌，不需要输入中文牌名。网络模式的游戏键直接生效；宝可梦的数字/字母选择需Enter确认。

### 川麻全部房规

换三张开/关；底分1/2/5/10；封顶8/16/不封顶；花猪2/16；龙七对额外根番0/1/2；自摸加一开/关；天地胡按封顶开/关。

### UNO全部房规

+4挑战、跳打、7换手/0传手、开局功能生效、错喊惩罚、同色数字双牌均为开/关；先手为庄家/下家。每项在房规页列出，使用方向键与Enter选择。

## 排版和兼容性

宝可梦页面适配宽窗口并排与窄窗口分页，推荐96列×30行以上，至少42列×20行。长说明可滚动，近期记录单独显示，不挤占选择区。棋盘多人模式建议更大的终端窗口以显示完整牌桌。

昵称可用英文；旧宝可梦存档按原昵称加载，不会自动把中文昵称改成英文。同一昵称不要同时打开多个冒险窗口。游戏中的中文显示仍要求终端使用支持中文的字体，但操作无需中文输入法。

## 宝可梦状态查看

对战首行显示对手剩余/总数，V+Enter查看队伍数量；P+Enter再选择伙伴，查看本级经验、升级还需经验与进化条件。长页用↑↓阅读，查看信息不消耗回合。十一种游戏使用不同背景曲，来源见game-audio.md。
