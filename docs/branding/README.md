# TableCard identity

## Name and tagline

- **Name:** TableCard
- **Tagline:** Your terminal. Your game table.
- **Short description:** Twelve games. Shared rooms and chat. One terminal.

The name keeps the connection to the existing Table-Card repository while giving the collection one consistent English wordmark. Existing executable names, network identifiers, save locations, and launcher filenames retain their current spelling.

## Logo

![TableCard logo](tablecard-logo.png)

The terminal window and command prompt represent the project's terminal interface. The diamond suggests a playing-card suit. The mark uses a dark background, a mint prompt, and an ivory frame and cursor. At small display sizes, use the full square image with its surrounding space; do not stretch it or place text inside the symbol.

| Role | Design color |
| --- | --- |
| Background | Dark navy, `#101820` |
| Prompt | Mint, `#72E5B2` |
| Frame and card symbol | Warm ivory, `#F5F2E9` |

The original PNG is retained at [tablecard-logo.png](tablecard-logo.png). GitHub's README displays it at 176 × 176 pixels. The palette values describe the design brief; the raster contains tonal variations.
