# 内存优化与全量自动测试报告

测量时间：2026-10-02 至 2026-10-03。Windows amd64、Go 1.26.3、Intel i7-13650HX；基线为优化前的 `6597195` 版本。

## 自动测试结果

执行 `scripts/test-project.ps1 -Race`，全仓库测试、`go vet ./...`、`go test -race ./... -count=1` 均通过。该次全仓库语句覆盖率为 **52.3%**，不是所有路径均已覆盖。随机牌局使个别包的覆盖率略有波动。

新增检查包括：

- 十一种游戏及大厅在 120×40、80×30、60×24 下能生成终端画面；十一种游戏按 Del 后释放对局状态。
- 斗地主全部十五种牌型、叫分/重发/过牌/非法持牌和三十局机器人完整对战；斗地主规则包覆盖率 97.9%。
- 贪吃蛇转向缓冲、反向输入、接触身体/边界、食物增长、满盘和加速；规则包覆盖率 95.7%。
- 俄罗斯方块双人/四人、同七袋序列、重力/硬降/消行、同周期触顶、机器人推进和快照隔离；该次规则包覆盖率 85.5%。
- 宝可梦全部章节的六次挑战门槛、剧情事件、八徽章、联盟冠军与后篇；存档恢复、冠军后全队倒下、三次摇球、商店/进化/电脑。章节测试使用高等级和低敌方 HP 的夹具隔离流程，不代表自然升级曲线和平衡性已验收；规则包覆盖率 65.8%。
- 九种联机模式各三十次创建、开局和最后真人离开，共 270 个房间；确认房间、引擎、运行记录、连接索引清空。另有 HTTP 身份鉴权和 WebSocket 生命周期集成测试。
- 四首音乐的前 2048 个解码立体声采样与原解码器完全相同；模拟 EOF 后重启曲目和关闭流程通过。未调用真实音频设备，不能替代扬声器试听。
- 新的终端排版函数与 Lip Gloss 原函数的字节结果相同，包含 ANSI、中文、表情与组合字符。
- 实际运行 Windows PowerShell 5.1 的服务启动器，确认九种联机模式和连接地址；PowerShell 5.1/7 均能停止自己启动的服务。发现并修复了 PowerShell 7 自动转换 JSON 日期后丢失 UTC 语义的问题；错误启动时间记录仍会拒绝停止进程。

测试存档及战绩使用临时目录。实际终端输入延迟、不同终端宿主的字体/鼠标体验和真人完整牌局仍需游玩验收。

## 客户端进程内存

`scripts/measure-memory.ps1` 将客户端模型编译为独立测试进程，宽 120、高 40，预热后二十次采样取中位数，每 20ms 重新生成画面。宝可梦包含 120 条历史消息。两次测量使用相同机器和编译器。

以下是**测试模型进程**的工作集，包含 Go 测试运行时；不包含 Windows Terminal/Conhost、实际 Bubble Tea 输入和输出循环，也未开启音乐。不是用户完整游戏窗口的总内存保证。

## 实现与取舍

1. 缓存有限种麻将牌、棋盘格的终端样式；棋盘缓存最多 512 项，麻将缓存最多 81 项，不随对局数量无限增长。
2. 宝可梦按游戏对象、历史版本、窗口宽度复用历史换行与标题；新记录和窗口变化会使缓存失效，退出时释放对游戏对象的引用。日志仍保留最近 120 条。
3. 对齐排版只测量每行一次并预分配结果；围棋连通块和数子使用固定大小栈工作区，保留全局同形判定和原计分行为。
4. MP3 隐藏随机寻址接口，按顺序解码；循环时重新打开内嵌曲目，不构建整首曲目的寻址索引。输出仍为 44100Hz，沿用原重采样质量和音量。
5. 最后房间退出后的下一个服务端节拍回收空闲页；至少间隔十秒，只在房间为空时请求回收，不在每帧强制 GC。退出客户端对局时清除棋盘、控制器和聊天内容。
6. 默认 GOGC=50；客户端 Go 内存软预算 64MiB、最多两个执行核心；服务端软预算 128MiB、最多四个执行核心。已有 GOGC/GOMEMLIMIT/GOMAXPROCS 环境配置优先。软预算限制 Go 管理的内存，不是整个进程的硬上限；降低默认执行核心数适合本机多开，较大服务器可显式提高。

这些设置在频繁渲染下增加较小堆的回收频率，缓存则减少重复分配。本机代表性渲染时间未出现明显退化；没有测试所有网络并发量和机器配置。

## 复测方法

在项目目录执行：

```powershell
./scripts/test-project.ps1 -Race -Benchmarks -Launchers
./scripts/measure-memory.ps1 -Label my-sample
./scripts/measure-server-memory.ps1 -BeforeBinary '旧版本的服务端EXE绝对路径'
```

报告及 CSV 保存到忽略提交的 `runtime/`。源码检查和性能探针需要 Go；`-Race` 还需要 MinGW GCC。脚本只在测试进程内临时设置 GNU C11 和编译器路径，并恢复环境。收到玩家包的人无需安装这些开发工具。

`-Launchers` 会在随机测试端口开启并关闭专用服务，测试 Windows PowerShell 5.1 的启动以及 5.1/7 的停止逻辑，不打开游戏窗口。可单独运行 `scripts/test-launchers.ps1`；它通过现有启动器寻找或构建当前程序。

例如需要较大服务端预算，可在启动前设置：

```powershell
$env:GOMEMLIMIT = '256MiB'
$env:GOMAXPROCS = '8'
./start-table-card.ps1 -ServerOnly
```

更新便携包后应关闭旧客户端并重新打开；已有后台服务需由房主结束后再启动，运行中的进程不会自动换成新版程序。桌面的 `牌桌停止服务.bat` 停止本项目记录中的默认 1781 端口服务，随后运行 `启动牌桌.bat`；结束服务会中断该服务的现有对局，宜在对局结束后操作。其他端口使用 `scripts/stop-local-server.ps1 -Port 端口`。
