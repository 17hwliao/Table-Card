# 宝可梦 · 关都文字冒险

## 启动与输入

纯终端，本地冒险可离线进行；联网时提供玩家对战、伙伴交换及跨模式聊天。双击桌面 `牌桌宝可梦.bat` 或包内 `start-pokemon.bat`；大厅选 `P`。入口会尝试连接配置的服务，失败仍可冒险。联网参数示例：`table-card.exe -pokemon -name Alice -server 192.168.1.20:1781` / `./start-pokemon.ps1 -Name Alice -Server 192.168.1.20:1781`。默认昵称无需手动输入中文；继续旧进度时保留原昵称。

## 对手数量、经验与进化

- 对战说明首行持续显示对手剩余/总数以及当前出场编号，包括当前出战精灵。输入 `V` + Enter 或选择“查看对手队伍数量”，查看总数、剩余、已击败与后备数；查看信息不消耗战斗回合。
- 输入 `P` + Enter，队伍列表每只伙伴下方直接显示“升到 LvN 还需多少经验”，无需进入详情；按编号打开详情，首屏先显示下一级经验目标和进化条件，之后列出 HP、累计经验、本级经验及招式完整效果。长页用 ↑/↓ 阅读，对战中也能查看。
- 下一等级和进化所需经验使用伙伴实际成长曲线计算；Lv100明确显示满级，经验不会出现负数或Lv101目标。旧存档的成长数据修正以新版数据迁移说明为准。
- 详情列出下一进化对象及条件：等级进化显示还差多少级和多少经验；道具进化列出所需进化石；通信进化可在玩家交换完成时触发，兼容的本地模拟入口与实际交换分开。伊布列出多个可选分支，无后续进化则标明最终阶段。
- 等级进化在升级时触发。捕获时已经达到进化等级的伙伴会显示“下次升级进化”和下一等级所需经验，例如 Lv10 铁甲蛹需要再获得331经验升到 Lv11。满级但未进化的伙伴会明确提示无法再通过升级触发进化。
- 本模式使用独立的 CC0 冒险曲，冒险中按 F9 开关声音；模式首页用 M。其他模式音轨及来源见 `game-audio.md`。

输入**本页显示的数字，再按 Enter**。字母入口也需 Enter：`M` 地区地图、`C` 城市中心、`W` 世界地图、`H` 指南、`P` 队伍、`B` 背包、`Q` 支线、`L` 训练家联机中心。菜单编号是当前页的编号，不是物品/物种的固定ID；固定ID只用于下表的完整英文指令。`[` / `]` 或左右键翻页，`0` / Esc 返回上层；本地战斗中返回对战行动。`↑/↓` 阅读较长说明，PgUp/PgDn 阅读历史。F1 规则、F5/Ctrl+S 存档、F9 音乐、Del 保存返回模式菜单；玩家对战期间Del表示认输。

界面分成状态、地区或对战说明、编号行动、近期记录和输入栏。宽窗口把地图与菜单并排；小窗口上下排列并减少每页选项，不把长剧情挤入行动区。至少42列×20行，建议96列×30行以上。所有说明和菜单仍用中文显示，操作不用输入中文。

## 玩家联机、对战与交换

双方先连接同一个服务端，使用不同昵称，每个身份只开一个窗口。房主把启动窗口里的局域网 `IP:端口` 发给朋友；不要把回环地址发给其他电脑。朋友可先用 `join-table-card.bat` 连接，再在大厅按 `P`，或使用带 `-Server` 参数的冒险启动器。跨互联网仍需可达的房主网络和端口，本项目没有中继。

1. 输入 `L` + Enter 打开训练家联机中心，先选择“同步队伍 / 刷新在线训练家”。另一位玩家也需进入中心并同步最新进度。
2. 按本页编号选择在线训练家，再选择对战或交换。正在本地战斗、已有邀请或正在对战时不能再邀请。
3. 对战邀请需对方接受；双方至少持有300金币，开始时各押300。对战使用恢复后的队伍副本，不消耗冒险队伍的HP和PP。输入 `1–4` + Enter 选招，`S 1–6` + Enter 换人；双方提交后统一结算。
4. 赢家获得双方押金，净赚300金币；输家净失300金币；平局各退300。`Del`退出或断线按认输处理。邀请90秒未接受失效；当前回合3分钟超时，双方都未提交行动则判平，一方已提交则未提交的玩家判负。服务重启后未完成对战退还押金。
5. 交换先选自己的伙伴，再选对方的伙伴，查看双方物种、等级后确认发送；对方接受才一次性交换，保留等级、经验、招式和PP。可通信进化的伙伴在交换时进化。等待邀请处理期间相关档案锁定，不能同时继续冒险或修改交换对象。

在线侧栏在终端至少120列时展示所有模式的玩家、房间及状态。`F4`打开紧凑玩家选择器，`↑/↓`选人、`Enter`选私聊对象；`F6`全服、`F7`当前房间、`F8`私聊。按 `/`输入消息，`Enter`发送，`Esc`返回；输入时记录仍实时更新。`F3`提供编号中文短语。全服消息和发给自己的私聊可跨游戏接收；离线只保留冒险，不发送网络消息。

## 原创伙伴专属技

151个物种各有对应的原创命名属性招式，不宣称是官方招式。教学要求Lv20及两枚徽章，或Lv20及三个支线；每只伙伴500元，只收费一次，替换第四招。统一威力95、命中100、PP8、物种主属性；遵循现有速度、克制与PP消耗规则。进化后保留学习资格，并变成新物种对应的招式；治疗恢复PP，存入/取出与存档保留资格。

## 战斗范围

四个招式槽（可教学原创专属技）、PP、速度先后、十五类属性克制、双属性、睡眠/冰冻/麻痹/中毒/灼伤、道具回合、换人、经验与升级、石头与交换进化。敌方选择有PP的有效攻击或异常招式，全部由本地串行事件循环处理。

训练家、道馆馆主、联盟对手和剧情对手登场时，记录播报其名字、派出的第一位伙伴和队伍总数；状态栏在整个对战期间持续显示对手名。播报文字为本项目编写。招式说明区可查看威力、命中、效果概率与能力变化；威力不等于固定扣血，实际伤害受等级、能力、属性与战斗状态影响。伙伴详情也列出每一招的说明，未学习的招式槽显示“未学习”，不会补入无关招式。

物种基础能力、属性、捕获率、基础经验、151种的升级学习表和成长曲线统一采用第一世代红/蓝资料，不再按属性给所有精灵补入毒粉。空招式槽保持“未学习”，已有存档的非法模板招式会修正；进化前合法学过的招式可以保留。快、普通、较慢、慢四种成长曲线分别结算，等级100的总经验不是统一100万。旧存档保留等级及本级经验进度比例，迁移到对应物种的曲线。

伤害结算包括等级、第一世代物理/特殊分类、能力变化、本系1.5倍、克制、217–255/255随机浮动；固定伤害单独处理。实现能力升降（-6至+6）、先制、异常、混乱、吸血、反作用、连续攻击、屏障、寄生种子、蓄力、休息回合、替身、封锁和忍耐等效果，日志显示实际扣血、回血及能力变化。换人后清除临时战斗状态。

这是同人改编：固定个体值且没有努力值；要害率、20%自行解冻、束缚与模仿的部分行为简化，不复现卡带漏洞。变身复制对手属性、非HP能力、能力变化和招式（各5PP），保留自身HP、等级、经验与永久物种；纹理复制对手当前属性。换人或结束后恢复原招式与属性，捕捉不会把变身数据永久写进队伍。聚宝功不会另外掉落金币。原创专属技明确标为本作原创，不混称为官方招式。

每章的普通探索绑定一张明确的红版地图（例如真新镇北的1号道路、常磐森林、月见山1层），采用原始10个遇敌槽的256份权重。遭遇信息显示具体地点、等级范围及物种百分比；这些百分比是已经遇敌后的物种分布，选择“进入草丛”或输入 `grass` 会主动触发一次遭遇。章内城市和原创建筑是本作导航合并，不宣称整片地区共用同一官方分布。伊布、御三家、化石和传说精灵不随机进入这些普通遭遇表。紫苑宝可梦塔探索需要西尔佛检视镜；狩猎地带暂用普通战斗捕捉流程，没有实现原版石头/诱饵流程。

## 捕获概率与三次摇球

单球概率模型参考第一世代红/蓝的实现资料，受球种、最大/剩余HP、物种捕获率与异常状态影响。未使用现代版本的通用球倍率：超级球的HP分母也与其他球不同。

设球随机上限 A：精灵球255、超级球200、高级球150；HP分母 B：超级球8、其他12。状态奖励 S：睡眠/冰冻25，中毒/灼伤/麻痹12，无状态0。物种捕获率参数为 C，N=A+1。

```text
W = floor(floor(MaxHP × 255 / B) / max(floor(CurrentHP / 4), 1))
P = min(S,N)/N + max(0,min(C+1,N-S))/N × min(W+1,256)/256
```

大师球 P=1。三个独立关卡各以 `P^(1/3)` 通过，因此三次全部通过的总概率仍是P；每750毫秒揭示一关结果，任一失败立即打开精灵球并触发野生对手回合。三次都通过后捕获成功。原版第一世代的摇球视觉规则与此不同；此处按本项目要求改编，不能用于解释卡带原版的摇球次数。

投球时一次生成并保存三个结果，演出只揭示已有结果；退出或重启会恢复同一过程，不重抽该次结果。不能捕捉训练者的伙伴，球在投出时扣除。

参考：[pret/pokered 捕捉实现](https://github.com/pret/pokered/blob/master/engine/items/item_effects.asm)。本项目独立表达概率公式，没有复制其汇编代码。

## 本地存档

存档位于系统用户配置目录 `Table-Card/pokemon/<昵称摘要>.json`，Windows 通常为 `%APPDATA%/Table-Card/pokemon/`。新版存档Version3兼容旧版，迁移保留等级与本级经验进度比例，按真实成长曲线重算经验，并修正非法模板招式；保存地区建筑、原创委托状态及专属技资格。支持人物进度、背包、队伍/电脑、图鉴、本地战斗双方HP/PP/状态、捕获待揭示结果与近期120条记录。每条冒险指令及摇球步骤都会保存，Del与Ctrl+C也先保存。存档写入临时文件并完成写盘，再替换目标文件；加载校验版本、大小与数据范围。

同一昵称请只开一个窗口，当前没有跨进程本地存档锁；不同昵称对应独立文件。损坏存档不会自动覆盖，界面会报错；先自行备份，再决定是否用 `new yes` 重置。本地冒险不依赖服务端或数据库；联机中心会同步冒险档案到服务端，使用档案版本控制与双方确认结算对战金币、交换及通信进化，再同步回本地。退出联机中心后须按菜单恢复本地冒险，避免用旧本地档案覆盖联机结果。
