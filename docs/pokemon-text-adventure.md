# 宝可梦 · 关都文字冒险

## 启动与输入

纯终端、离线、单机。双击桌面 `牌桌宝可梦.bat` 或包内 `start-pokemon.bat`；大厅选 `P`。参数示例：`table-card.exe -pokemon -name Alice` / `./start-pokemon.ps1 -Name Alice`。默认昵称无需手动输入中文；继续旧进度时保留原昵称。

输入**本页显示的数字，再按 Enter**。字母入口也需 Enter：`M` 地区地图、`C` 城市中心、`W` 世界地图、`H` 指南、`P` 队伍、`B` 背包、`Q` 支线。菜单编号是当前页的编号，不是物品/物种的固定ID；固定ID只用于下表的完整英文指令。`[` / `]` 或左右键翻页，`0` / Esc 返回上层；战斗中返回对战行动。`↑/↓` 阅读较长说明，PgUp/PgDn 阅读历史。F1 规则、F5/Ctrl+S 存档、F9 音乐、Del 保存返回模式菜单。

界面分成状态、地区或对战说明、编号行动、近期记录和输入栏。宽窗口把地图与菜单并排；小窗口上下排列并减少每页选项，不把长剧情挤入行动区。至少42列×20行，建议96列×30行以上。所有说明和菜单仍用中文显示，操作不用输入中文。

## 原创伙伴专属技

151个物种各有对应的原创命名属性招式，不宣称是官方招式。教学要求Lv20及两枚徽章，或Lv20及三个支线；每只伙伴500元，只收费一次，替换第四招。统一威力95、命中100、PP8、物种主属性；遵循现有速度、克制与PP消耗规则。进化后保留学习资格，并变成新物种对应的招式；治疗恢复PP，存入/取出与存档保留资格。

## 战斗范围

四个招式槽（可教学原创专属技）、PP、速度先后、十五类属性克制、双属性、睡眠/冰冻/麻痹/中毒/灼伤、道具回合、换人、经验与升级、石头与交换进化。敌方选择有PP的有效攻击或异常招式，全部由本地串行事件循环处理。

这是改编玩法：统一三级方经验曲线、固定个体值与无努力值；招式学习表是简化代表性集合；睡眠时长、解冻、持续伤害与失败处理也采用本项目规则。基础能力与经验值取自现行 PokéAPI 事实数据，钢/妖精映射回第一世代类型范围，特攻作为统一特殊能力。不会复现原版全部招式、能力数值、成长曲线、特殊判定或卡带漏洞。

## 捕获概率与三次摇球

单球概率模型参考第一世代红/蓝的实现资料，受球种、最大/剩余HP、物种捕获率与异常状态影响。未使用现代版本的通用球倍率：超级球的HP分母也与其他球不同。

设球随机上限 A：精灵球255、超级球200、高级球150；HP分母 B：超级球8、其他12。状态奖励 S：睡眠/冰冻25，中毒/灼伤/麻痹12，无状态0。物种捕获率参数为 C，N=A+1。

```text
W = floor(floor(MaxHP × 255 / B) / max(floor(CurrentHP / 4), 1))
P = min(S,N)/N + max(0,min(C+1,N-S))/N × min(W+1,256)/256
```

大师球 P=1。三个独立关卡各以 `P^(1/3)` 通过，因此三次全部通过的总概率仍是P；每750毫秒揭示一关结果，任一失败立即打开精灵球并触发野生对手回合。三次都通过后捕获成功。原版第一世代的摇球视觉规则与此不同；此处按本项目要求改编，不能用于解释卡带原版的摇球次数。

投球时一次生成并保存三个结果，演出只揭示已有结果；退出或重启会恢复同一过程，不重抽该次结果。不能捕捉训练者的伙伴，球在投出时扣除。

参考：[pret/pokered 捕捉实现](https://github.com/pret/pokered/blob/master/engine/items/item_effects.asm)。本项目独立表达概率公式，没有复制其汇编代码。

## 本地存档

存档位于系统用户配置目录 `Table-Card/pokemon/<昵称摘要>.json`，Windows 通常为 `%APPDATA%/Table-Card/pokemon/`。新版存档Version2兼容读取Version1，并保存地区建筑、原创委托状态及专属技资格。支持人物进度、背包、队伍/电脑、图鉴、战斗双方HP/PP/状态、捕获待揭示结果与近期120条记录。每条指令及摇球步骤都会保存，Del与Ctrl+C也先保存。存档写入临时文件并完成写盘，再替换目标文件；加载校验版本、大小与数据范围。

同一昵称请只开一个窗口，当前没有跨进程存档锁；不同昵称对应独立文件。损坏存档不会自动覆盖，界面会报错；先自行备份，再决定是否用 `new yes` 重置。此模式不上传进度，不依赖服务器或数据库。

## 数据与作品来源

离线JSON由 `scripts/rebuild-pokemon-data.ps1` 从 [PokéAPI CSV](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv) 提取名称、属性、能力、捕获率和进化事实；游戏运行无需网络。保留其BSD-3-Clause许可证，源码见 `internal/pokemon/POKEAPI_LICENSE.md`，便携包见 `licenses/POKEAPI_LICENSE.md`。

Pokémon及角色名称属于其权利人的作品与商标。本模式为关都背景的同人改编，对话和程序为本项目编写；没有附带官方图像、音乐、ROM或对话脚本。项目GPL许可证不主张第三方角色和名称的权利。

此前版本已通过章节门槛、八徽章、冠军及后篇、三次摇球、存档恢复与输入快捷键隔离等自动测试；本次菜单、支线与教学改动完成构建和静态检查，尚未运行新功能自动测试；章节流程使用战斗夹具，不代表自然升级曲线与难度已验收。不同终端的真实输入和排版、完整自然游玩仍需实机验收。详见 [内存优化与测试报告](memory-and-test-report.md)。
