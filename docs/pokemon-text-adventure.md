# 宝可梦 · 关都文字冒险

## 启动与输入

纯终端、离线、单机。双击 `start-pokemon.bat` 或桌面 `牌桌宝可梦.bat`。大厅快捷键为 `P`；直接程序参数为 `table-card.exe -pokemon -name 小岚`，脚本参数为 `./start-pokemon.ps1 -Name 小岚`。

输入命令后按 Enter；命令与参数用空格分隔。F1 规则、F5/Ctrl+S 存档、F9 音乐、PgUp/PgDn 查看历史、Esc 清空输入、Del 保存并返回本模式菜单。字母、数字、斜杠都进入文字输入框，不触发其他游戏快捷键。音乐沿用现有骗子酒馆背景曲，摇球使用合成提示音。

## 战斗范围

四个代表性招式、PP、速度先后、十五类属性克制、双属性、睡眠/冰冻/麻痹/中毒/灼伤、道具回合、换人、经验与升级、石头与交换进化。敌方选择有PP的有效攻击或异常招式，全部由本地串行事件循环处理。

这是改编玩法：统一三级方经验曲线、固定个体值与无努力值；招式学习表是简化代表性集合；睡眠时长、解冻、持续伤害与失败处理也采用本项目规则。基础能力与经验值取自现行 PokéAPI 事实数据，钢/妖精映射回第一世代类型范围，特攻作为统一特殊能力。不会复现原版全部招式、能力数值、成长曲线、特殊判定或卡带漏洞。

## 捕获概率与三次摇球

单球概率模型参考第一世代红/蓝的实现资料，受球种、最大/剩余HP、物种捕获率与异常状态影响。未使用现代版本的通用球倍率：超级球的HP分母也与其他球不同。

设球随机上限 A：精灵球255、超级球200、高级球150；HP分母 B：超级球8、其他12。状态奖励 S：睡眠/冰冻25，中毒/灼伤/麻痹12，无状态0。物种捕获率参数为 C，N=A+1。

```text
W = floor(floor(MaxHP × 255 / B) / max(floor(CurrentHP / 4), 1))
P = min(S,N)/N + max(0,min(C+1,N-S))/N × min(W+1,256)/256
```

大师球 P=1。三个独立关卡各以 `P^(1/3)` 通过，因此三次全部通过的总概率仍是P；每750毫秒揭示一关结果，任一失败立即打开精灵球并触发野生对手回合。三次都通过后捕获成功。原版第一世代的摇球视觉规则与此不同；此处按本项目要求改编，不能用于解释卡带原版的摇球次数。

投球时一次生成并保存三个结果，演出只揭示已有结果；退出或重启会恢复同一过程，不重抽该次结果。不能捕捉训练者的伙伴，球在投出时扣除。

参考：[pret/pokered 捕捉实现](https://github.com/pret/pokered/blob/master/engine/items/item_effects.asm)。本项目独立表达概率公式，没有复制其汇编代码。

## 本地存档

存档位于系统用户配置目录 `Table-Card/pokemon/<昵称摘要>.json`，Windows 通常为 `%APPDATA%/Table-Card/pokemon/`。支持人物进度、背包、队伍/电脑、图鉴、战斗双方HP/PP/状态、捕获待揭示结果与近期120条记录。每条指令及摇球步骤都会保存，Del与Ctrl+C也先保存。存档写入临时文件并完成写盘，再替换目标文件；加载校验版本、大小与数据范围。

同一昵称请只开一个窗口，当前没有跨进程存档锁；不同昵称对应独立文件。损坏存档不会自动覆盖，界面会报错；先自行备份，再决定是否用 `新冒险 确认` 重置。此模式不上传进度，不依赖服务器或数据库。
